# VEON brand implementation — HORIZON 1440

The supplied November 2024 VEON guide takes precedence over the accompanying 2022 guide where they differ. Original uploaded PDFs are reference material, not public application assets.

- Logo (2024 pp. 8–11): official supplied yellow SVG on a black navigation surface; official black SVG in the printable board brief. Original paths, colors, proportions and safe-zone canvases remain intact. HORIZON 1440 is a separate product label outside the logo canvas.
- Color (p. 16): black/white masterbrand surfaces; yellow #FFC836 reserved for the official logo and favicon. Blue #00005C, #00408F and #007FC1 anchor interface controls and risk matrices. Secondary violet, orange, pale blue, green and yoke inform charts and labeled statuses. Tints and darker status text provide legibility.
- Pattern (p. 17): the geometric pattern is extracted as vector artwork from the supplied guide and applied subtly to page headings.
- Typography (p. 20): self-hosted Open Sans Light/Regular/Semibold/Bold for interface text; Montserrat Light/Regular/Semibold for significant numbers. Font licenses are distributed alongside the font files under public/brand/fonts. Headings use light/regular weights and sentence case where practical.
- Digital applications (pp. 28–29): black navigation, white work surfaces, thin rules and blue gradient sections. Favicon uses the supplied black logo on yellow.
- The dashboard deliberately uses a consistent light work surface with black navigation, including on devices that prefer dark mode. This follows the supplied digital examples and avoids mismatched inherited theme colors.

This release is visual: existing risk scoring, market feed readiness, synthetic data labels, moon calculations, stored records and owner-only access are preserved. No new live data integration is implied by the redesign.
